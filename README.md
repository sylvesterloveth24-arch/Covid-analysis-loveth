# Covid-analysis-loveth

## Description
This repository contains a Python data analysis project on global COVID-19 epidemiology data.

## Project Structure
* `Covid.Analysis.ipynb`: Main Jupyter Notebook containing data loading, processing, and exploratory data analysis using Pandas.

## Features
* Loads COVID-19 dataset directly into Pandas DataFrames.
* Displays dataset shape, column previews, and summary statistics.
* Designed to run seamlessly on Google Colab or local Jupyter environments.
